# Импорт товаров ЧекЧек — подробности формата

Справочник для редких случаев. Основные правила — в SKILL.md.

## Детект колонок

Импортер сопоставляет заголовки с полями по подстроке (без учёта регистра):
`бренд`, `наименование`, `маска`, `артикул`, `фиксированное количество баллов`,
`фиксированный процент`, `мин. цена`, `макс. цена`. Первый ещё не занятый
заголовок, содержащий ключевик, забирает поле. Позиции колонок не важны.
Обязательны: бренд + хотя бы одно из наименование/артикул.

Заголовки, не совпавшие ни с одним ключевиком, могут матчиться на
пользовательские поля кабинета (совпадение точное, без учёта регистра) —
случайные служебные колонки типа «№» безвредны.

Испорченный заголовок — фатальная ошибка всего файла. Ошибка в строке данных
валит только эту строку; остальные импортируются, ошибки собираются списком
с номерами строк.

## Разделители и кодировка

- `.csv` → точка с запятой (формат Excel в русской локали), всё остальное → таб.
- Кодировка UTF-8. Экспорт из ЧекЧека идёт с BOM — при повторном импорте это ок.
- Многострочные ячейки — в кавычках (стандарт CSV), парсер их понимает.
- Числа принимают и запятую, и точку как десятичный разделитель; пробелы внутри
  числа вычищаются. Нечисловое значение — ошибка строки.

## Ячейка бренда может быть многострочной

Каждая строка ячейки — вариант написания бренда:

- Бренд ищется по всем строкам (сначала первая) среди существующих брендов
  кабинета и их альтернативных написаний, без учёта регистра. Не найден —
  создаётся под именем из первой строки.
- Все строки участвуют в генерации масок из артикулов.
- Строки, не совпавшие с именем бренда, дописываются в его альтернативные
  написания. Дописываются — но никогда не удаляются: файл, где варианта нет,
  не считается его отзывом. Очистить список можно только в кабинете.

## Баллы, процент, автоакции

- Баллы XOR процент: оба заполнены — ошибка строки.
- Значения квантуются с шагом 0,01: то, что квантуется в 0 — ноль.
  Отрицательное — ошибка.
- Файл содержит колонку баллов или процента → пустая/нулевая ячейка означает
  «без начислений»: прежняя автоакция товара архивируется. Обе колонки
  отсутствуют в заголовке → автоакции вообще не трогаются.
- Автоакция у товара одна (1:1); новая загрузка заменяет старую (старая
  архивируется, начисленные по ней чеки остаются привязаны к ней).

## Цены

Пустая ячейка мин./макс. цены = «не менять сохранённое значение», а не
«очистить». Заполненная — перезаписывает.

## Повторная загрузка

Импорт — «добавить/обновить», не «синхронизировать»: загрузка файла ничего не
удаляет и не архивирует, кроме автоакций по правилу выше. Файл может заменить
только то, что было создано файлом; созданное руками в кабинете файл не трогает.

## Даты

Везде, где встречаются даты — `ДД.ММ.ГГГГ` (ISO из старых выгрузок тоже
принимается).
