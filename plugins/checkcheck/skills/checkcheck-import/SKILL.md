# Импорт товаров в ЧекЧек

Скилл превращает исходный файл поставщика (обычно Excel-«приложение» с брендами,
масками и баллами) в готовый к загрузке файл импорта товаров ЧекЧека и проверяет
его по правилам импортера. Итог всегда — `.tsv` (разделитель — табуляция, UTF-8).

## Порядок работы

1. Получи исходный файл (xlsx/csv/tsv). Посмотри на заголовки и первые строки,
   чтобы понять структуру. Если структура сильно нестандартная — сначала приведи
   её к колонкам с нужными заголовками (см. «Формат» ниже), не меняя данные.
2. Собери файл импорта:
   `python scripts/build_import.py исходник.xlsx -o итог.tsv`
   Скрипт сам находит колонки бренда и масок по ключевым словам и приводит маски
   к формату (см. «Правила масок»). Если скрипт падает или исходник слишком
   нестандартный — сделай те же преобразования вручную по правилам ниже.
3. Провалидируй результат:
   `python scripts/validate_import.py итог.tsv`
4. Покажи пользователю итог: сколько строк и масок, все ОШИБКИ и предупреждения
   валидатора — своими словами, с номерами строк. Ошибки исправь (сам, если
   очевидно как; иначе спроси пользователя) и прогони валидатор заново.
   Не отдавай файл, пока валидатор показывает ошибки.
5. Если валидатор сообщил, что баллы/процент пустые во всех строках — это
   развилка, спроси пользователя: файл только про каталог/маски → пересобери
   с `--drop-column "фиксированное количество баллов"` (и процента, если есть);
   снятие автоакций задумано или товары новые → оставь; либо проставь баллы.
6. Отдай пользователю готовый `.tsv`.

## Формат файла импорта

Колонки импортер находит по ключевым словам — подстроке в заголовке, без учёта
регистра (позиция колонки не важна, лишние колонки не мешают):

| Поле | Ключевое слово в заголовке | Обязательно |
|---|---|---|
| Бренд | `бренд` | да |
| Наименование товара | `наименование` | да, либо артикул |
| Артикул | `артикул` | да, либо наименование |
| Маски | `маска` | нет, но без неё не будет матчинга по чекам |
| Баллы | `фиксированное количество баллов` | одно из двух, либо ничего |
| Процент | `фиксированный процент` | одно из двух, либо ничего |
| Мин./макс. цена | `мин. цена` / `макс. цена` | нет |

Один заголовок не должен содержать два ключевых слова сразу.

Расширение решает разделитель: `.tsv` — табуляция (наш стандарт),
`.csv` — точка с запятой (так пишет Excel). Ячейки с переносами строк
оборачиваются в кавычки — стандартное поведение csv-библиотек, импортер это
понимает.

Ячейка бренда может быть многострочной: первая строка — каноничное имя,
остальные — альтернативные написания (например, «Турбо» и «Turbo»);
маски матчатся по всем вариантам. Сохраняй такие ячейки как есть.

## Правила масок

- В ячейке масок каждая маска — на своей строке (перенос строки внутри ячейки).
  Запятая — не разделитель масок; если в исходнике маски перечислены через
  запятую, разбей их по строкам.
- Каждая маска должна содержать бренд (в любом месте, любым из вариантов
  написания) — иначе она может матчить чужие товары. Если бренда в маске нет —
  допиши его в начало, убрав повтор слов на стыке (написание слов возьми из
  бренда): бренд «Витамикс Марин» + маска «МАРИН ОМЕГА-3 №30» →
  «Витамикс Марин ОМЕГА-3 №30». Маску, в которой бренд уже есть
  («смазка Turbo 952857»), не трогай.
- Матчинг по чекам регистронезависимый: дубликаты масок, отличающиеся только
  регистром, схлопывай в одну (оставляй первую по порядку).
- Одинаковая маска у двух разных товаров — почти всегда ошибка исходника:
  покажи пользователю и уточни.

## Критичные правила импортера (за этим следит валидатор)

- **Баллы XOR процент.** В строке заполнено либо одно, либо другое. Оба сразу —
  строка не импортируется.
- **Пустые баллы — это действие, а не «пропустить».** Если колонка баллов или
  процента в файле есть, пустая (или нулевая) ячейка снимает с товара
  автоакцию. Если начисления менять не нужно — убери обе колонки из файла
  целиком, тогда акции останутся как были.
- Отрицательные значения — ошибка строки. Значение меньше 0,01 квантуется в
  ноль и считается нулём. Десятичный разделитель — точка или запятая, оба ок.
- Ошибка в строке валит только эту строку, остальные импортируются. Ошибка в
  заголовке валит весь файл.
- Импорт **добавляет и обновляет**, но ничего не удаляет: бренд ищется среди
  существующих (по имени и альтернативным написаниям, без учёта регистра) и
  создаётся только если не найден.
- Даты, если встречаются — в формате `ДД.ММ.ГГГГ`.

Подробности и редкие случаи (многострочный бренд с вариантами написания,
поведение цен, повторная загрузка) — в `references/import-format.md`; читай его,
когда вопрос выходит за рамки правил выше.

## Пример преобразования масок

Исходная ячейка (бренд «Витамикс Дэйли»):
```
КОЛЛАГЕН БЬЮТИ 5500МГ №30, КОЛЛАГЕН БЬЮТИ 5500МГ 30
Коллаген Бьюти 5500мг №30, Коллаген Бьюти 5500мг 30
```
Итоговая ячейка:
```
Витамикс Дэйли КОЛЛАГЕН БЬЮТИ 5500МГ №30
Витамикс Дэйли КОЛЛАГЕН БЬЮТИ 5500МГ 30
```
(четыре маски стали двумя: варианты, отличавшиеся только регистром, схлопнуты;
бренд дописан, потому что в масках его не было).
